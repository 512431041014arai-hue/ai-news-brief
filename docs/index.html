転職視点：AIインフラ・MLOps領域の投資が拡大中。GPU運用やクラウド基盤の知見は今後も強みになる。

3. 三井不動産、熊本にフィジカルAI・半導体拠点「PASTEC」始動

熊本県合志市の「くまもとサイエンスパーク」内に、自動運転車や産業ロボットなど現実空間で動く「フィジカルAI」向け半導体の実装・パッケージング技術を研究する拠点「PASTEC」を新設。7月27日には台湾2機関を含む国内外7機関との連携協定を締結した。国の地域未来戦略でも重点分野に選定されている。

★6. 日本のAIスタートアップ、2026年1〜3月期の資金調達額が2025年通年を上回る

転職視点：資金が集中する企業ほど採用も積極化しやすい。大型調達のニュースは注目企業リストの更新材料になる。
